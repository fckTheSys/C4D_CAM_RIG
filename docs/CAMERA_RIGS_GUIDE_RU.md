# Camera Rigs — практический гид

Пакет **Camera Rigs** создаёт четыре самостоятельных типа камер. Выберите тип
до начала анимации: режим не переключается внутри уже созданного Cine-рига.
Так в сцене нет лишних контроллеров и параметров, которые ничего не делают.

## Быстрый выбор

С версии **0.5.5** создание через панель даёт ригу номер, например
`Cine Trajectory 003`, и камере имя `CAM | Cine Trajectory 003`. Корень получает
случайный цвет один раз при создании. Имена и цвет можно менять вручную.

### Поиск и переключение камер пакета

В группе **Camera Rigs in scene** введи имя рига или камеры в поиск.
Обычные камеры вне пакета не показываются. Выбор в списке и стрелки ←/→:

- если viewport смотрит через камеру пакета — переключают его сразу;
- если активен свободный вид или сторонняя камера — только выбирают кандидата;
  для переключения нажми **Activate camera**.

Выделенная в Object Manager камера не считается активной во viewport.
**Select camera rig** выбирает корень выбранного кандидата и не включает камеру.
**Look through camera** по-прежнему включает камеру выделенного рига/его дочернего
объекта. Стрелки идут по отфильтрованному списку и отключаются на его краях.
При пустом поисковом результате включение и стрелки недоступны.

После ручного добавления, удаления, копирования или переименования объектов нажми
**Refresh cameras**. При открытии панели, смене документа и создании через панель
список обновляется сам; на каждом кадре сцена не сканируется.
Выбор из списка не меняет Object Manager, ключи и настройки рендера.
Одинаковые имена дубликатов дополнены коротким идентификатором в списке.

| Если нужен кадр | Создавай | Анимируй |
| --- | --- | --- |
| Облёт объекта или героя | **Orbit** | Orbit angle, Radius, Height |
| Проезд по заранее нарисованному пути | **Trajectory** | Progress и точки сплайна |
| Операторская камера без заданного пути | **Free** | координаты и поворот Free Controller |
| Вид глазами персонажа, шаги и прыжок | **CK_CAM** | Progress, Body Y, Pan/Tilt/Roll |

**Orbit** — положение камеры задают угол, радиус, высота и центр. `360°` —
один полный круг, `720°` — два. Больше Radius — камера дальше от центра;
меньше — ближе. Height поднимает или опускает камеру относительно центра.
Orbit Center можно перемещать, чтобы перенести весь облёт.

**Trajectory** — редактируй объект `Trajectory` или назначь свой сплайн/Tracer в `Path` и
ставь ключи `Progress`: `0%` — начало, `100%` — конец. Ключи дальше друг от
друга во времени дают более медленный проезд. Плоский участок F-Curve —
остановка. Progress не гарантирует равномерную мировую скорость на сплайне
неравной длины; для ощущения скорости правь тайминг и касательные F-Curve.

**Free** — выбери `Free Controller` через кнопку Movement и ставь обычные
ключи PSR. Это режим для ручной операторской работы: движение не привязано к
сплайну и не требует Progress.

**CK_CAM** — POV на маршруте. `Progress` задаёт путь и скорость: более тесные
ключи означают более быстрый ход. Walk автоматически реагирует на скорость.
`Body Y` добавляется к высоте глаз: положительное значение — прыжок, отрицательное
— приседание или амортизация. Полное описание POV-параметров с примерами —
[CK_CAM Parameters](../prototypes/simple_camera/PARAMETERS_RU.md).

## Общие контроллеры Cine

| Группа | Параметр | Практический эффект |
| --- | --- | --- |
| Main | Local Offset X/Y/Z | Небольшая поправка камеры после движения. Больше модуль — сильнее сдвиг. Не используй вместо основного маршрута. |
| Look | Aim mode | Manual — ручные углы; World Target — объект сцены; Local Target — анимируемый Null перед движущейся камерой. |
| Look | Pan / Tilt / Roll | Горизонтальная, вертикальная поправка и завал горизонта после наведения. Ноль возвращает чистую композицию. |
| Camera | Output camera | Справочная ссылка на единственную выходную камеру. Объектив, фокус, DOF и экспозиция меняются в её нативных настройках. |
| Inertia | Strength | Больше — камера сильнее отстаёт от движения. Ноль полностью выключает слой. |
| Inertia | Response | Больше — отставание быстрее догоняет источник. |
| Inertia | Damping | Больше — меньше пружинных колебаний; около 100 — почти без раскачки. |
| Shake / Drift | Strength | Общая сила быстрого Shake или медленного Drift. Ноль пропускает вычисление слоя. |
| Shake / Drift | Frequency | Больше — рисунок меняется чаще. Для Drift обычно подходит низкое значение. |
| Shake / Drift | Position / Rotation | Амплитуда сдвига в сантиметрах и поворота в градусах. Начинай с малых чисел. |
| Shake | Pattern seed | Другой номер — другой, но воспроизводимый рисунок шума. |

Сначала сделай маршрут и композицию при нулевых Strength эффектов. Затем
включай Inertia, Drift и Shake по одному. Анимируй силу и амплитуду; Response,
Damping, Frequency и Seed оставляй постоянными для кадра.

## Панель Camera Rigs

| Группа панели | Кнопка | Действие |
| --- | --- | --- |
| Create rig | Orbit / Trajectory / Free / CK_CAM | Создаёт выбранный самостоятельный риг и выделяет его корень. |
| Selected rig | Rig controls | Выделяет корень: здесь User Data всех контроллеров. |
| Selected rig | Movement | Выделяет Orbit Center, Trajectory, Free Controller или Path CK_CAM — в зависимости от типа. |
| Selected rig | Target | World Target: выбирает назначенный объект; Local Target: выбирает локальный Null; Manual: выбирает корень с углами взгляда. |
| Selected rig | Camera / Lens | Выделяет выходную камеру для нативных оптических настроек. |
| Viewport | Look through camera | Переключает текущий viewport на камеру выбранного рига. |
| Tools | Inspect rig | Проверяет структуру, ссылки и встроенные Python Tags. Это не проверка рендера. |
| Tools | Help / Parameters | Краткая подсказка по режимам, эффектам и защите сбросов. |
| Reset | Reset framing | Обнуляет Local/Body Offset XYZ и Pan/Tilt/Roll. |
| Reset | Disable effects | Для Cine обнуляет Inertia/Shake/Drift; для CK_CAM — Walk/Shake/Drift. |

Кнопки от Selected rig до Reset доступны, когда выделен корень рига или любой
его дочерний объект. Оба сброса сначала проверяют затронутые параметры: если
на любом есть анимационный трек, сброс не меняет ничего и не удаляет ключи.
Неактивное состояние без выделенного рига — ожидаемое поведение, а не ошибка.

## Сцена, Redshift и ограничения

После создания в `.c4d` записывается runtime двух Python Tags. Пакет нужен для
создания, навигации и меню; для открытия уже сохранённой сцены он не нужен.
На другой машине требуется совместимая Cinema 4D с выполнением Python Tags и
используемый рендерер. Cine-риги используют стандартную камеру, если Redshift
недоступен. **CK_CAM требует Redshift Camera**; fallback для него не реализован.

Сохраняй масштаб корня `1`, не используй frozen transforms и expression-драйверы
на источниках движения. Для Cine сплайны должны оставаться статическими и иметь
одну секцию. Для CK_CAM Path должен быть статическим сплайном; доступны Linear,
Bezier, B-Spline, Cubic, Akima, открытые и замкнутые маршруты.
Рендер на ферме и Redshift motion blur требуют отдельной проверки на конкретной
ферме. Подробности переноса CK_CAM: [portability acceptance](CK_CAM_PORTABILITY.md).

## Свой маршрут через Tracer — с версии 0.5.3

1. Создай Tracer в режиме **Connect Objects**, добавь в его список объекты,
   которые задают точки маршрута, в нужном порядке.
2. Перетащи **сам Tracer** в **Path** в User Data корня Trajectory или CK_CAM.
3. Перемещай связанные объекты, чтобы редактировать форму пути. Камера обновляется
   по живому результату Tracer; конвертация в сплайн и bake не нужны.
4. Поставь ключи **Progress** от 0% до 100%. Контроллеры маршрута оставь без ключей.

Больше расстояние между точками при прежнем тайминге — выше скорость. В CK_CAM
это также меняет темп походки. Linear даёт резкие углы; Cubic/Akima/B-Spline —
сглаженную форму, которая может проходить иначе относительно контроллеров.
Выбирай форму в настройках Tracer, оценивая видимый сплайн в сцене.

Внешний маршрут можно переносить и поворачивать при настройке. В CK_CAM его
трансформация учитывается в длине и направлении походки. Внутренний дефолтный
сплайн после назначения внешнего можно удалить. Кнопка **Movement** выбирает
именно назначенный Path. При пустой/ошибочной ссылке смотри **Status**: движение
останавливается, прежний путь не продолжает использоваться.

Режим Tracer **Trace Paths** с накоплением истории, анимация его контроллеров,
expression-драйверы контроллеров и деформеры пути не входят в этот сценарий.
Изменение формы пути пересчитывает историю инерции/походки с начала диапазона.
На длинном диапазоне первый расчёт после изменения может быть дороже повторного.

Обновление пакета влияет на **новые** риги. Уже созданные риги хранят свою версию
кода в Python Tags и автоматически не обновляются.

## Управление взглядом через Null — с версии 0.5.4

С версии 0.5.4 во всех ригах доступен **Local Target**. Чтобы управлять взглядом
нулём, выбери его в **Aim mode**, нажми кнопку **Target** и двигай выбранный Null.
Он расположен в 300 см по локальной +Z базы камеры. X — влево/вправо, Y —
вниз/вверх; увеличение Z делает реакцию на то же смещение X/Y мягче.
Ключи ставятся на обычные координаты Null, режим не анимируется.

Local Target следует за позицией маршрута, смещениями Body/Position Offset и
инерцией. Он находится рядом с Aim в иерархии, поэтому не наследует поворот
взгляда и не создаёт циклической зависимости. Оси — базовые оси движения рига;
автоматического поворота по касательной пути этот режим не добавляет.
Pan/Tilt/Roll и Shake/Walk/Drift применяются после наведения: с ненулевыми
поправками итоговая камера может смотреть немного в сторону от Null.

**World Target** позволяет заменить ссылку своим объектом и анимировать его.
В CK_CAM ссылка теперь редактируемая; Use Target заменён на Aim Mode.
Пустая World Target или цель внутри Aim/Camera дают диагностическую ошибку.
В Manual и Local Target ссылка World Target не участвует в расчёте.
Не помещай Local Target в точку камеры: направление в таком случае не определено.
Существующие риги не обновляются при установке пакета; создавай новый риг 0.5.4.

## Legacy и запекание

### Эксперимент: анимация пути Cine Trajectory

В новом риге 0.5.5 включи **Experimental: Animated Tracer**. Назначь Tracer Connect
Objects в Path, поставь ключи Progress 0–100% и анимируй Position отдельных Null
маршрута — например, чтобы путь во время проезда огибал препятствие. Столкновения
не вычисляются: форму и безопасный обход задаёшь ты.

Первый эксперимент поддерживает 2–64 Null без детей, неизменный список/порядок,
Position-ключи, Linear/Cubic/Akima/B-Spline. Tracer и его настройки статические,
масштаб контроллеров 1, frozen transforms и expression-драйверы не поддерживаются.
Bezier остаётся доступным для статического Tracer; его автоматические касательные
не входят в исторический sampler этого эксперимента. Галочка — настройка кадра,
без анимации. Неподдерживаемый случай даёт сообщение Status.

При включённой инерции учитывается история изменения формы пути. Правка ключа
сбрасывает кеш истории; переход на дальний кадр с холодным кешем дороже повторного.
История ограничена существующим пределом Cine — 500 секунд от начала проекта.
Даже с постоянным Progress камера может двигаться вместе с меняющейся формой пути.
CK_CAM пока требует статическую геометрию маршрута; эксперимент применяется только
к Cine Trajectory. Сохранённая сцена не импортирует файлы плагина при вычислении.

### Legacy

Legacy CamRig остаётся отдельным ригом для существующих сцен. Camera Rigs не
конвертирует legacy-анимацию, не выполняет Upgrade/Repair и не имеет полного
bake в обычную камеру. Полный bake нужен как отдельная безопасная операция,
потому что он создаёт и перезаписывает ключи.
