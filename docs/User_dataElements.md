Типы данных и элементы интерфейса
1. Основные типы данных

Эти типы определяют, какую информацию будет хранить поле.

Boolean (Логическое)
Значения «Да/Нет» (True/False). Обычно отображается в виде галочки (Check Box).

Integer (Целое число)
Числа без плавающей запятой (например: 1, 10, -5). Используется для переключателей, счетчиков и дискретных значений.

Float (Число с плавающей запятой)
Дробные числа. Чаще всего применяется для слайдеров и параметров с плавной регулировкой (проценты, метры, радианы).

Vector (Вектор)
Состоит из трех числовых полей (X, Y, Z). Используется для координат, масштаба, направлений или цвета в формате RGB.

String (Строка)
Текстовое поле для ввода слов, названий или путей к файлам.

Time (Время)
Значения времени в секундах или кадрах, привязанные к таймлайну.

Color (Цвет)
Открывает стандартную палитру выбора цвета.

2. Интерфейсные элементы (UI Elements)

Определяют, как выбранный тип данных отображается в окне атрибутов.

Button (Кнопка)
Позволяет запускать скрипты (Python) или команды XPresso при нажатии.

Slider (Слайдер)
Ползунок для быстрой регулировки числовых значений (Float или Integer).

Cycle (Выпадающий список)
Позволяет выбрать одно значение из заранее заданного списка
(например: «Тип 1», «Тип 2», «Тип 3»).

Radio Buttons (Радио-кнопки)
Группа кнопок, в которой можно выбрать только один вариант.

Group (Группа)
Контейнер для организации элементов интерфейса.
Группы можно сворачивать или отображать как вкладки (Tabs).

Separator (Разделитель)
Визуальная линия или пустое пространство для логического разделения элементов интерфейса.

3. Специальные (сложные) типы данных

Дополнительные инструменты для расширенного контроля параметров.

Spline (Сплайн)
Интерактивный график для управления кривыми
(например, для настройки спада силы, скорости анимации или влияния параметров).

Gradient (Градиент)
Редактор цветовых переходов, позволяющий создавать сложные цветовые схемы.

In/Exclude (Включить / Исключить)
Список, в который можно перетаскивать объекты из сцены для дальнейшей обработки.

Link (Ссылка)
Поле для привязки конкретного объекта, тега или материала.

Filename (Имя файла)
Поле с кнопкой обзора, позволяющее выбрать путь к файлу на диске.
