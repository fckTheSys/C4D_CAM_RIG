# Python Tag and Button Interaction
## Cinema 4D 2026 – Camera Rig Builder

---

# 1. Overview

Python Tag используется как основной механизм логики рига камеры.

Он размещается на объекте **Main_Camera** и отвечает за:

- чтение параметров User Data
- обработку нажатий кнопок
- вычисление позиции Look_Target
- обновление трансформаций объектов рига
- управление вспомогательными функциями

Python Tag выполняется **каждый кадр** при обновлении сцены.
