# Upgrade CamRig 1.4 → 1.5

Миграция только явная. Перед работой сохраните копию сцены. Выделите корень рига или его потомка → Upgrade Selected Rig. При неоднозначном выборе появится список ригов.

## Что поддерживается

Поддерживается точный embedded runtime локального baseline 1.4, сохранённый в camrig/legacy_140.txt; сравнение нормализует переводы строк. Не каждый скрипт с надписью «1.4» автоматически совместим. Неизвестный или отредактированный код не перезаписывается.

Требуется целая иерархия, Align и Target tags. Собственные CTracks круга, frozen transforms и нестандартный масштаб круга блокируют автоматическое обновление. Прямое исправление сцены перед повторным Upgrade остаётся решением автора сцены.

## Что изменяется

1. Сохраняются оригинальные код и priority раннего тега в BaseContainer корня: namespace PLUGIN_ID, META_BACKUP_CODE / META_BACKUP_PRIORITY.
2. Добавляются только новые группы/UD; старые DescID не пересоздаются.
3. Center/Height и Plane HPB инициализируются из текущих локальных трансформаций круга.
4. Обновляются hard limits Orbit/Radius без изменения значений и ключей.
5. Устанавливаются ранний runtime и поздний focus, приоритеты -20 / -10 / 0 / 20, schema 2.
6. Если присутствует legacy Vibrate, он удаляется явной командой, а не expression.

Команда представляет одну Undo-операцию. Повторное обновление известного актуального рига не создаёт дубликаты. В случае исключения выполненные изменения откатываются через Undo. При Undo C4D может заменить экземпляры объектов: скрипты должны повторно искать объекты в документе.

## Что сохраняется

Старые значения, DescID, CTracks, времена/значения/интерполяция и тангенты ключей, внешние ссылки, трансформация корня и поза круга. Сравнение обеих камер проведено на кадрах 0/12/30/60, включая Orbit spline-ключи и Drift. Legacy baseline вычислялся дважды на кадр для стабилизации прежних одинаковых priorities; версия 1.5 проверялась после одного вычисления. Подробности: [приёмка](ACCEPTANCE_1_5.md).

Для немедленного восстановления используйте Undo. Сохранённый исходный код доступен в metadata для ручной диагностики/восстановления; отдельная команда Downgrade не реализована. Для полного возврата после закрытия сцены используйте её исходную копию.

## Break и Repair

Break не выполняет полный Bake Camera. Новые трансформации, Aim Offset, новые цели/auto-focus и анимированный multi-turn Orbit могут требовать bake, поэтому операция блокируется с объяснением. Консервативно блокируется любой Orbit CTrack, даже если его ключи укладываются в один оборот.

Repair работает только с известной schema 2: восстанавливает отсутствующие Align, Target, Focus и runtime-стадии, проверяет priorities/links. Неизвестный код не заменяет и legacy автоматически не мигрирует.
