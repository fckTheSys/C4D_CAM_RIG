# CamRig project instructions

## Project

CamRig is a Cinema 4D 2026 Python command plugin. The runtime boundary is `camrig/tag_embedded.py`; its `EMBEDDED_RUNTIME_VERSION` must match `camrig/config.py:PLUGIN_VERSION`.

The current source of truth is the implementation in `camrig/`, `cam_rig_builder.pyp`, `camrig/ud_template.json`, and `docs/SUMMARY.md`. Treat `docs/Interaction.md` and `docs/Technical Specification.md` as historical/reference material unless code confirms them.

## Commands

- Static checks (explicit .py and .pyp): `& 'C:\Program Files\Maxon Cinema 4D 2026\resource\modules\python\libs\win64\python.exe' tools/check_project.py`
- Production build: `python tools/build_production_release.py --development --keep-docs`
- MCP setup and smoke tests: `docs/MCP_SETUP.md`

Use Cinema 4D's bundled Python 3.11.4 for compatibility checks. A normal system Python check is not runtime proof for the `c4d` module.

## Boundaries

- Baseline of `feature/improvements` is preserved in commit `00f7490`; work on `feature/orbit-controls-targets`. Preserve user changes; never reset, merge, delete, rename, or push without an explicit request.
- Do not commit secrets, MCP tokens, `.c4d` scenes, or generated bytecode.
- Cinema 4D MCP can modify scenes and save files. Keep per-call approval for destructive operations.
- `exec_python` and Python operators provide process-level access to Cinema 4D and must only be enabled for a trusted development session.
- Prefer path-based entity handles when names are ambiguous.

## 1.5 safeguards

- Runtime/schema versions are separate. Keep both stages portable, with priorities -20 / -10 / 0 / 20.
- Run tests/c4d_acceptance.py only in C4D on the main thread; it creates its own documents. Binary fixtures/results go under ignored tests/artifacts/.
- Re-resolve objects after Undo: C4D can replace object instances; stale Python references are not document state.
- Do not auto-upgrade legacy scenes, overwrite unknown embedded code, or remove expression objects during evaluation.
- Native HUD creation is not exposed by the Python API. Do not fake Show/Hide or assume Add to HUD has a supported command ID.
- LICENSE vs production commercial text is unresolved. Use a unique private development output directory; no public release.
