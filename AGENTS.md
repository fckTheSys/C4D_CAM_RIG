# CamRig project instructions

## Project

CamRig is a Cinema 4D 2026 Python command plugin. The runtime boundary is `camrig/tag_embedded.py`; its `EMBEDDED_RUNTIME_VERSION` must match `camrig/config.py:PLUGIN_VERSION`.

The current source of truth is the implementation in `camrig/`, `cam_rig_builder.pyp`, `camrig/ud_template.json`, and `docs/SUMMARY.md`. Treat `docs/Interaction.md` and `docs/Technical Specification.md` as historical/reference material unless code confirms them.

## Commands

- Syntax: `& 'C:\Program Files\Maxon Cinema 4D 2026\resource\modules\python\libs\win64\python.exe' -m compileall camrig cam_rig_builder.pyp`
- Production build: `python tools/build_production_release.py --sources-only`
- MCP setup and smoke tests: `docs/MCP_SETUP.md`

Use Cinema 4D's bundled Python 3.11.4 for compatibility checks. A normal system Python check is not runtime proof for the `c4d` module.

## Boundaries

- Preserve existing user changes in `feature/improvements`; never reset, merge, delete, rename, or push without an explicit request.
- Do not commit secrets, MCP tokens, `.c4d` scenes, or generated bytecode.
- Cinema 4D MCP can modify scenes and save files. Keep per-call approval for destructive operations.
- `exec_python` and Python operators provide process-level access to Cinema 4D and must only be enabled for a trusted development session.
- Prefer path-based entity handles when names are ambiguous.
