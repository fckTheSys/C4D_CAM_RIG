# Camera Rigs 0.5.2 — private development package

Меню создания и обслуживания Cine Orbit / Trajectory / Free / CK_CAM POV в Cinema 4D 2026.
Частный command ID: **10699230**. Не является публичным релизом.

Полный русскоязычный справочник по режимам, параметрам и кнопкам:
[Camera Rigs Guide](../docs/CAMERA_RIGS_GUIDE_RU.md).

## Установка

Распаковать папку `Cine_CAM` целиком в пользовательскую папку `plugins`.
После обычного запуска C4D найти **Camera Rigs (Cine + CK_CAM)** в Extensions или через поиск
команд Shift+C. Откроется компактное меню с кнопками, как у старого CamRig.
Панель можно закрепить в layout. Сохранённому ригу плагин не нужен.

## Создание

| Кнопка | Управление движением |
| --- | --- |
| Orbit | Angle — обороты (360° полный круг), Radius — радиус, Height — высота, Center — центр |
| Trajectory | Сплайн и Progress 0–100%; F-Curve прогресса задаёт разгон/остановку |
| CK_CAM POV | Progress задаёт движение, Walk реагирует на скорость; Body Y — прыжок |
| Free | Ключи обычных координат и вращения Free Controller |

Одна камера, одна общая панель User Data, без переключателя режима. Новый риг
создаётся в начале координат; перемещай его корень. Legacy-риг не обновляется.

## Команды из старого меню

- Select Rig / Motion Controller / Select Target / Select Camera — навигация по
  выделенному ригу; разрешены выделения его дочерних объектов.
- Look Through Camera — включает его выходную камеру во viewport.
- Rig Inspector — проверяет структуру, ссылки UD и согласованность заголовков
  двух встроенных стадий; показывает диагностический статус runtime. Это не render QA.
- Reset Framing — обнуляет XYZ-смещение и Pan/Tilt/Roll.
- Disable Effects — устанавливает силы Inertia/Shake/Drift в ноль.

Сбросы прекращаются до изменений, если хотя бы один затронутый параметр имеет
анимационный трек. Ключи не удаляются и не перезаписываются. Сброс записывается
одной операцией Undo. Внешние связанные контроллеры лучше выбирать через риг.

Не перенесены Upgrade/Repair (нет миграции), Break User Data (это не полноценный
bake) и Reset All (слишком широкое действие). Полное запекание камеры пока не реализовано.

## Общие параметры

Offset XYZ сдвигает камеру; Pan/Tilt/Roll поправляют композицию после наведения.
Target автоматически смотрит на цель, Manual оставляет ручную ориентацию.
Оптика, фокус, DOF и экспозиция — на единственной нативной камере.

Inertia Strength: больше — сильнее отставание; Response: больше — быстрее догоняет;
Damping: больше — меньше колебаний, 100 — критическое затухание.
Shake — быстрый шум; Drift — медленные поправки. Strength умножает Position (см)
и Rotation (градусы). Frequency задаёт темп рисунка, Seed меняет рисунок.
Strength=0 пропускает соответствующий расчёт. Силу и амплитуды можно анимировать;
Response/Damping/Frequency/Seed задаются для кадра, без ключей.

## Передача сцены

В .c4d хранится весь runtime Python Tags. Плагин нужен только для создания/команд.
На ферме нужны совместимая C4D с выполнением Python Tags и используемый рендерер,
например Redshift для RS-камеры. Cine-риги при отсутствии Redshift создают стандартную камеру. CK_CAM требует Redshift: стандартного fallback у него пока нет.
Локальные проверки не означают проверку конкретной фермы или Redshift motion blur.

Инерция: Main Take, обычные ключи, масштаб 1, без frozen transforms и expression-
драйверов источников. Сплайн — статический редактируемый, одна секция. Предел истории
500 секунд; холодная оценка длинного диапазона дороже повторного просмотра.
Progress использует нативную параметризацию, равномерная скорость на любом сплайне
не гарантируется. Геометрические сглаживания и автоматическая конверсия legacy не входят.

## Общая панель 0.5.2

Сверху четыре кнопки создания. Ниже навигация по выделенному ригу, большая кнопка
просмотра через камеру и отдельно сбросы. Команды выключены без выделенного рига.
Панель проверяет выделение лёгким обходом родителей раз в 300 мс, без чтения runtime;
полная проверка выполняется только при команде. User Data остаётся нативной.
CK_CAM Reset Framing сбрасывает Body XYZ и Pan/Tilt/Roll, сохраняя Height и Progress.
Disable Effects отключает Walk/Shake/Drift. Защита ключей и Undo такие же, как у Cine.
Параметры POV подробно описаны в `ck_runtime/PARAMETERS_RU.md`
в установленном пакете. Старый отдельный CK_CAM можно оставить: пакет не регистрирует
его command ID повторно. Исходные legacy-риги не меняются.

Панель разделена на пять компактных групп: Create rig, Selected rig, Viewport,
Tools и Reset. В первой строке находятся четыре кнопки создания. Описания режимов
вынесены в Help / Parameters и полный Guide, поэтому сама панель остаётся короткой.
Runtime и данные сцен не изменяются при работе панели.
