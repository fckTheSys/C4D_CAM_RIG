# CamRig 2 — Motion P3 (0.3.0 prototype)

**Legacy:** универсальный вариант сохранён без изменений runtime. Для новых
камер используются [три отдельные сборки](../cine_variants/README.md).
Контрольные суммы сохранённого кода — в [LEGACY.md](LEGACY.md).

Отдельный прототип постановочной камеры. [Архитектура и параметры](../../docs/CAMRIG_2.md).

В Cinema 4D Script Manager открой `builder.py` из этой папки и выполни.
Скрипт создаёт новый риг в активном документе одной операцией Undo.
Старые риги и CK_CAM не изменяются. Для разработки используй отдельный документ.
Плагин не устанавливается; Python Tag хранит runtime внутри сцены.

Выбери корень для орбиты и наведения, Camera — для оптики и вида.
По умолчанию: радиус 500 см, высота 150 см, цель в центре, объектив 36 мм.

В `Movement mode` выбери Orbit, Trajectory или Free. Для пути анимируй Progress;
для свободной камеры — координаты/вращение Free Controller. Панорама/наклон/крен,
локальное смещение и оптика общие. Режим выбирается для кадра, без ключей режима.
Параметры находятся в одной панели User Data с раскрытыми группами Main / Orbit /
Trajectory / Free / Look / Camera / Effects. Режим выбирается в Main. Неактивные
поля пока не блокируются: штатного флага блокировки User Data нет. Отдельный плагин не нужен
ни для интерфейса, ни для исполнения рига. Нужны совместимая C4D с Python Tags
и выбранный рендерер; реальная рендер-ферма пока не проверена.

`acceptance.py` запускается в C4D на главном потоке через `run()` и использует
собственные документы. Результат не заменяет ручную приёмку интерфейса,
визуальную проверку сравнения со старым ригом и тест Redshift motion blur.
`acceptance_modes.py:run()` отдельно проверяет траекторию, Free и переключение режимов.

P3 добавляет Inertia, Shake и Drift. По умолчанию все Strength = 0: эффекты
отключены. Ключами Strength можно плавно вводить/убирать эффект. Response,
Damping, Frequency и Pattern seed — постоянные настройки кадра; ключи на них
пока не поддерживаются. `acceptance_effects.py:run()` проверяет эффекты в C4D,
`python -m unittest discover -s prototypes/cine_camera -p test_effects_math.py`
из корня репозитория — чистую математику.
