# CK_CAM — параметры камеры от первого лица

Эта памятка описывает текущую реализацию CK_CAM 0.1.0. Числа «по умолчанию»
взяты из сборщика рига. Примеры для POV ниже — стартовые настройки для ручной
пробы, а не автоматически установленные пресеты.

Выберите корень рига `Simple Camera PROTOTYPE` и откройте **User Data**.
Внутри групп короткие названия повторяются: например, `Strength` в Walk и
`Strength` в Shake управляют разными эффектами. Ниже приведены полные имена.
Позиционные значения указаны в сантиметрах для сцены с соответствующим масштабом.

## Как собирать движение

1. **Path + Progress**: куда идёт персонаж и с какой скоростью.
2. **Height + Body**: высота глаз, приседание, прыжок и дополнительные смещения.
3. **Look**: куда персонаж смотрит и как поворачивает голову.
4. **Walk**: покачивание от шагов, связанное с движением по маршруту.
5. **Shake / Drift**: дополнительная нерегулярная тряска и медленное покачивание.
6. **Camera**: угол обзора и остальные штатные настройки объектива.

Сначала настройте маршрут и взгляд с нулевой силой всех трёх эффектов. Затем
добавляйте Walk, Drift и при необходимости Shake по одному: так проще понять,
какой слой делает движение слишком сильным.

## Route / Body — маршрут и положение глаз

| Параметр | По умолчанию | Что означает и что даёт изменение |
| --- | --- | --- |
| **Path** | Ссылка на маршрут | С версии 0.5.3 сюда можно перетащить другой редактируемый сплайн или Tracer в режиме Connect Objects. Один источник задаёт движение, длину пути, скорость и походку. Можно перемещать точки, объекты-контроллеры Tracer и сам внешний путь при настройке. Анимируйте Progress; геометрию и контроллеры Tracer оставьте статическими. Пустая/ошибочная ссылка останавливает движение с сообщением Status. |
| **Progress** | 0% | Положение вдоль длины маршрута: 0% — начало, 50% — половина длины, 100% — конец. Больше — дальше по пути; меньше — ближе к началу. Это положение, а не отдельный регулятор скорости. Значения за пределами 0–100% ограничиваются концами пути, зацикливания нет. |
| **Height** | 170 см | Базовая высота глаз над точкой пути. Больше — взгляд более высокого персонажа; меньше — низкий POV, ребёнок или приседание. Учитывайте высоту самого сплайна: если Path уже находится на уровне глаз, Height дополнительно поднимет камеру. |
| **Body X** | 0 см | Постоянное или анимированное боковое смещение по оси X корня рига. Положительное значение — в сторону +X, отрицательное — −X. Чем больше модуль числа, тем дальше смещение. Подходит для небольшого обхода препятствия или отклонения корпуса. |
| **Body Y** | 0 см | Добавка к Height по вертикали рига. Плюс — подъём/прыжок, минус — приседание или амортизация после приземления. При Height=170 и Body Y=−30 высота относительно пути будет 140 см. |
| **Body Z** | 0 см | Дополнительное смещение по оси Z корня рига. Плюс — к +Z, минус — к −Z. Используйте для небольшой коррекции положения корпуса; основное продвижение по маршруту удобнее задавать Progress. |
| **Status** | После вычисления: Ready | Ready — риг выполнил расчёт. ERROR с пояснением — обнаружена неподдерживаемая настройка. Исправьте причину: изображение в этот момент может показывать последний корректный результат. Поле информационное. |

**Body X/Z не поворачиваются вслед за взглядом или изгибом пути.** Это оси
корня рига, поэтому +Z не всегда означает «вперёд по маршруту». Body Y остаётся
вертикалью рига даже при наклоне головы. Для переноса всего маршрута целиком
можно статически передвинуть/повернуть корень, сохраняя его масштаб 1.

### Как менять скорость

Для пути длиной 600 см переход Progress от 0% до 100% за 6 секунд даёт среднюю
скорость 100 см/с. Те же ключи за 3 секунды — 200 см/с. При плавных кривых
мгновенная скорость будет меняться между ключами.

- Раздвигаете ключи по времени — персонаж проходит тот же участок медленнее.
- Сдвигаете ключи ближе — быстрее.
- Делаете горизонтальный участок кривой Progress — остановка.
- Снижаете Progress со временем — движение назад по пути.
- Меняете длину Path, сохраняя время и проценты, — меняется реальная скорость.

Следите за кривой между одинаковыми значениями: касательные могут создать
небольшое движение даже при одинаковом Progress на двух ключах. Для остановки
сам участок кривой должен быть горизонтальным. Ступенчатые ключи Progress
не поддерживаются. Шаги учитывают движение по маршруту, а смещения Body в их
расчёт не входят.

## Look — взгляд и повороты головы

| Параметр | По умолчанию | Что означает и что даёт изменение |
| --- | --- | --- |
| **Aim Mode** | World Target | С 0.5.4 заменяет Use Target. Manual — углы Pan/Tilt/Roll; World Target — взгляд на назначенный объект; Local Target — взгляд на Null, который следует за базой камеры. Режим выбирается без ключей. |
| **Target / World Target** | Ссылка на объект Target | В режиме World Target сюда можно перетащить свой объект. Его координаты можно анимировать. Близкая цель даёт более резкий поворот при движении камеры; далёкая — более спокойный. В остальных режимах эта ссылка не влияет на взгляд. |
| **Local Target — Position XYZ** | (0, 0, 300) см | Координаты отдельного Null; выберите его кнопкой Target при режиме Local Target. X/Y меняют направление, Z — расстояние. Больше Z — мягче поворот от того же смещения X/Y. Null следует за маршрутом и прыжком, не наследует поворот взгляда. Можно ставить обычные ключи Position. Не ставьте его в (0,0,0). |
| **Pan** | 0° | Поворот головы по горизонтали. Ноль — без добавочного поворота; положительные и отрицательные значения поворачивают в противоположные стороны. Чем больше модуль угла, тем сильнее взгляд уходит в сторону. Переход 0→20° за секунду — умеренный поворот, за несколько кадров — резкий. |
| **Tilt** | 0° | Наклон взгляда вверх/вниз. Чем больше модуль, тем сильнее отклонение от исходного взгляда. Меняет направление камеры, а не высоту глаз: для приседания нужен Body Y. |
| **Roll** | 0° | Завал горизонта, как при наклоне головы к плечу. Небольшие углы дают наклон головы, большие — заметно косой кадр. Для спокойного POV начните с 0° и добавляйте по необходимости. |

Плюс и минус углов обозначают направления вращения вокруг соответствующей оси.
Для ориентира измените угол на +5° и проверьте направление в своём кадре:
поворот корня и Target влияют на то, как он выглядит на экране. Pan, затем Tilt,
затем Roll применяются последовательно, поэтому при больших углах они связаны.

В ручном режиме камера **не доворачивается автоматически по изгибу Path**.
Повороты на маршруте нужно задать Pan/Tilt или вести взгляд через Target.
Переключатель Aim Mode не анимируется и может изменить кадрирование при смене
режима. Прыжок применяется до наведения: с Target камера будет продолжать
смотреть на цель во время подъёма, что тоже меняет наклон взгляда.

## Motion / Walk — походка

| Параметр | По умолчанию | Меньше | Больше |
| --- | --- | --- | --- |
| **Walk Strength** | 1 | Ослабляет и смещения, и завал от шагов. 0 полностью убирает походку. 0,5 примерно вдвое уменьшает её амплитуду при той же скорости. | Усиливает всю походку. Не ускоряет персонажа и не учащает шаги. Значения выше 1 усиливают эффект сверх базового уровня. |
| **Step Length** | 70 см | На том же расстоянии помещается больше шагов: покачивание чаще. | Шаги реже, как при более длинном шаге. Не меняет время прохождения маршрута. Значение должно быть больше нуля. |
| **Walk Amplitude** | 2 см | Уменьшает вертикальное и боковое движение глаз. При 0 позиционного покачивания нет, но Walk Lean ещё может наклонять горизонт. | Голова заметнее движется вверх/вниз и в стороны. Это размах смещения, а не высота прыжка. |
| **Walk Lean** | 1° | Уменьшает попеременный завал от шагов. 0 оставляет позиционное покачивание без этого завала. | Горизонт сильнее наклоняется на каждом шаге. Это только вращение, положение глаз не меняется. |
| **Softness** | 0,8 | Вертикальное покачивание имеет более выраженный дополнительный изгиб внутри шага. | При приближении к 1 вертикальное покачивание становится простой плавной волной. Не сглаживает путь, ключи или отклик слайдеров; на боковой размах и Lean напрямую не влияет. |

Частота шага зависит от горизонтальной скорости по Path и Step Length. Например,
при скорости 140 см/с длина шага 70 см даёт примерно **2 шага в секунду**,
а 140 см — примерно **1 шаг в секунду**. Это частота движения головы; риг не
создаёт ноги, контакт с землёй или звуки шагов.

При замедлении Walk автоматически ослабевает, при остановке исчезает. На
горизонтальной скорости 100 см/с и выше достигается полная заданная сила.
Дальнейший разгон учащает шаги, но автоматически не увеличивает размах сверх
заданного Strength. Body-прыжок и чисто вертикальное движение пути не ускоряют
горизонтальные шаги.

Практически: при достаточной скорости `Strength=0,5` и `Amplitude=2` дают
позиционный размах до примерно 1 см по каждой из двух осей покачивания,
а `Lean=1` — завал до примерно 0,5°. На малой скорости эффект будет слабее.

## Motion / Shake — нерегулярная тряска

| Параметр | По умолчанию | Меньше | Больше |
| --- | --- | --- | --- |
| **Shake Strength** | 0 | Ослабляет весь Shake. 0 выключает его. | Усиливает позиционную и угловую тряску одновременно. Частоту не меняет. |
| **Shake Frequency** | 2 | Рисунок тряски меняется медленнее. | Рисунок меняется быстрее, появляется более частая дрожь. Размах задаётся другими полями. |
| **Shake Position** | 0,5 см | Меньше случайных смещений камеры. 0 оставляет только угловой Shake. | Камера сильнее смещается в своих локальных осях; особенно заметно движение относительно близких предметов. |
| **Shake Rotation** | 0,3° | Меньше случайных угловых отклонений. 0 оставляет только позиционный Shake. | Сильнее дрожат направление взгляда и горизонт. Даже небольшие углы могут быть заметны в кадре. |

Пока Shake Strength=0, изменения Frequency/Position/Rotation не видны.
Например, Strength=0,2 и Position=0,5 дают смещения не более примерно 0,1 см
по каждой локальной оси. Угловая составляющая масштабируется тем же Strength.

Frequency — скорость изменения случайного рисунка, а не точное число одинаковых
толчков в секунду: периодического ритма здесь нет. При Frequency=0 рисунок
замирает, но может оставить постоянное смещение/наклон. Для полного выключения
используйте Strength=0. Shake сам не усиливается от скорости и не гаснет при
остановке — для этого анимируйте Strength.

## Motion / Drift — медленное покачивание

Drift использует тот же принцип, что Shake, но отдельный случайный рисунок и
свою частоту. Его можно использовать как мягкое движение головы в паузе.
Автоматической модели дыхания здесь нет.

| Параметр | По умолчанию | Меньше | Больше |
| --- | --- | --- | --- |
| **Drift Strength** | 0 | Ослабляет весь Drift; 0 выключает. | Усиливает плавное смещение и поворот. |
| **Drift Frequency** | 0,15 | Более медленное изменение положения головы. | Более быстрое покачивание; на больших значениях может стать похожим на Shake. |
| **Drift Position** | 0,5 см | Меньше плавных смещений, при 0 — только угловое движение. | Сильнее «плавает» положение глаз. |
| **Drift Rotation** | 0,3° | Взгляд спокойнее; при 0 — только позиционное движение. | Сильнее плавно отклоняются взгляд и горизонт. |

Как и у Shake, нулевая Frequency замораживает рисунок, а нулевой Strength
выключает эффект. Drift может продолжаться, когда Progress стоит на месте.

## Seed — вариант случайного движения

**Seed**, по умолчанию **1**, находится в группе Motion. Меняет рисунок Shake
и Drift, не меняя их заданную силу и частоту. Больше не означает сильнее:
Seed=20 — просто другой вариант по сравнению с Seed=1.

Используйте целые числа. Дробная часть в расчёте отбрасывается, поэтому 1 и 1,5
дают один вариант. Выберите подходящее значение и оставьте его постоянным:
смена Seed внутри анимации может вызвать скачок рисунка. На Walk Seed не влияет.

## Camera — объектив и кадр

**Camera** — справочная ссылка на единственную выходную Redshift Camera.
**Lens controls** — подсказка о том, что объектив настраивается на самой камере.
Выберите объект Camera в иерархии или используйте `select_camera.py`.

При неизменном размере сенсора меньшее фокусное расстояние даёт более широкий
угол обзора и показывает больше окружения. Большее — более узкий кадр. Это
не меняет маршрут или физическую скорость камеры, но меняет впечатление от
движения. Фокус, экспозиция и глубина резкости — штатные настройки Redshift;
на корне CK_CAM их копий нет.

## Практические примеры для POV

### Спокойная ходьба

Попробуйте: Walk Strength **0,3**, Step Length **70**, Amplitude **1**, Lean
**0,2**, Softness **0,9**; Shake Strength **0**; Drift Strength **0,1**, Frequency
**0,15**, Position **0,5**, Rotation **0,3**. Сначала отрегулируйте время Progress.
Если шаги слишком частые, увеличьте Step Length. Если кадр слишком качается,
уменьшайте Strength или Amplitude; для завала отдельно уменьшайте Lean.

### Быстрый проход или бег

Сначала сократите время прохождения нужного участка Progress. Если ритм стал
слишком частым, увеличьте Step Length. Затем добавьте Strength/Amplitude по
вкусу. Увеличение одного Strength сделает бег только более тряским, но не быстрым.

### Остановка и взгляд в сторону

Сделайте горизонтальный участок Progress. Walk погаснет сам. Поставьте ключи
Pan, например 0° → 20° → 0°. Больше времени между ключами — спокойнее поворот,
меньше — быстрее. Небольшой Drift может продолжать движение головы в паузе.
Чтобы кадр застыл полностью, обнулите также Shake и Drift Strength.

### Приседание

При Height=170 анимируйте Body Y: **0 → −40 → 0**. Глаза опустятся до 130 см
относительно пути и вернутся. Чем глубже отрицательное значение, тем ниже
приседание. Tilt регулируйте отдельно, если персонаж должен посмотреть вниз.

### Прыжок и приземление

Пример при 30 кадрах/с; отсчёт относительно начала действия:

| Кадр | Body Y | Walk Strength | Что происходит |
| --- | --- | --- | --- |
| 0 | 0 см | 0,3 | Подход к прыжку. |
| 4 | −8 см | 0,3 | Небольшое приседание перед толчком. |
| 7 | 0 см | 0 | Отрыв; выключаем шаги на время полёта. |
| 15 | +60 см | 0 | Верхняя точка. |
| 23 | 0 см | 0 | Контакт с землёй на исходной высоте. |
| 25 | −5 см | 0 | Амортизация. |
| 30 | 0 см | 0,3 | Возврат к ходьбе. |

Сгладьте кривую Body Y и проверьте её между ключами. Большая вершина — выше
прыжок; больший промежуток между отрывом и контактом — дольше полёт. Progress
управляет перемещением вперёд во время прыжка. Риг не проверяет столкновения и
не подбирает физически правильную траекторию. Не дублируйте один подъём сразу
в Path и Body Y: смещения сложатся.

## Если результат непонятен

| Наблюдение | Что проверить |
| --- | --- |
| Кручу Shake/Drift Frequency, ничего не видно | Strength соответствующего слоя больше нуля? Есть ли движение времени? На одном кадре видно положение, скорость изменения оценивайте при воспроизведении. |
| Walk не виден | Меняется ли Progress? Достаточна ли горизонтальная скорость? Strength и Amplitude/Lean больше нуля? |
| Изменение пропало при перемотке | Для параметра с анимацией слайдер даёт временный предпросмотр. Запишите ключ, чтобы сохранить изменение. |
| Step Length/Frequency при редактировании меняет текущую позу | На время незаписанного изменения это значение используется как постоянное для предпросмотра фазы. После записи ключа результат определяется всей кривой параметра. |
| При остановке камера продолжает двигаться | Проверьте Drift, Shake, ключи взгляда и движение Target. Walk сам по себе гаснет при нулевой скорости пути. |
| Body X/Z сдвигает «не туда» | Смещение идёт по осям корня, а не по направлению взгляда или касательной Path. |
| Камера не поворачивает на повороте пути | В ручном режиме автоматического следования направлению пути нет. Задайте Pan/Tilt или используйте Target. |
| На слайдере достигнут край диапазона | Для позиций и углов можно ввести число вручную вне видимого диапазона. Step Length должен быть положительным, Softness — от 0 до 1. |

Описание сверено с `builder.py`, `runtime.py` и `motion_math.py` текущего рига.
