# GitHub workflow

The canonical repository is `https://github.com/fckTheSys/C4D_CAM_RIG`.

Before publishing, review the worktree, run the Cinema 4D Python checks, verify embedded-runtime version parity, and build a sources-only production package. Do not publish `.c4d` scenes, tokens, `.pyc`, or local MCP configuration.

Use a unique PluginCafe ID before distributing the plugin publicly. Releases should be tagged with the plugin version and include the generated production archive.
