# Установка и первый запуск — Cam Rig Builder

## 1. Куда копировать

Скопируйте каталог репозитория целиком в папку **plugins** активной версии Cinema 4D.

Примеры путей:

- `Документы\MAXON\Cinema 4D 2026_xxxxxxxx\plugins\C4D_CAM_RIG\`
- или `...\plugins\CamRig\` (имя папки может быть любым)

**Обязательно:** рядом в одной папке должны находиться:

- файл `cam_rig_builder.pyp`
- каталог `camrig\` со всеми `.py` и `ud_template.json`

Не копируйте только `.pyp` без пакета `camrig`.

## 2. Перезапуск C4D

Полностью закройте Cinema 4D и откройте снова.

## 3. Проверка загрузки

Откройте **Script Log** (Консоль Python / Script Manager — зависит от версии UI).

Ожидаемая строка:

```text
[CamRig] v1.4.0 loaded
```

Если видите `Import failed` — проверьте, что `camrig` лежит на одном уровне с `cam_rig_builder.pyp`.

## 4. Запуск команды

- Меню **Extensions / Расширения** → **Plugins** → **Cam Rig Builder**,  
  или поиск по имени команды в палитре команд.

## 5. Обновление версии

Замените файлы новой сборкой (лучше удалить старую папку плагина и скопировать заново, чтобы не осталось устаревших `__pycache__`).

## 6. Plugin ID (для публикации)

В `camrig/config.py` заданы числовые ID. Для публичного распространения получите уникальные ID на **PluginCafe** и подставьте в конфиг.
